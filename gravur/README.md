# Laser-Gravuren

Die Laser-Gravuren sind ansich einfach umzusetzen. Ich nutze verschidenen Rohlinge aus Holtz und Metall und graviere überwiegend Logo's.

## Holtz Schlüsselanhänger

<img title="" src="..\image\Schluesser-anhaenger-35.jpg" alt="" style="height:300px;" width="414">

Diese 35mm Durchmesser anhänger habe ich mit verschidenen Motiven graviert. Sie gibt es, z.B. bei Amazon im 100er Pack

[Anhänger Holtz 35mm](https://www.amazon.de/dp/B0BB74WB25?ref=ppx_yo2ov_dt_b_fed_asin_title)

Ich habe sie jeweils von beiden Seiten graviert. Wobei ich die Seiten unterschiedlich gestalte. 

## Schlüsselanhänger 40mm

Die Schlüsselanhänger 40mm sind deutlich Dicker als die 35mm variante. 

<img src="..\image\Schluesselanhaenger40v2.jpg" style="height:300px;">

Ansonsten gestallte ich sie ähnlich wie die 35mm. Das heißt, auf einer Seite das YFU Logo und die andere Seite variiert.
